## FAQ

### What is XCutors?

XCutors is a Windows desktop collection that bundles several popular Roblox Lua script executors—Volt, Synapse Z, Potassium, Wave—alongside a universal loader called xcutorsLoader that manages them from one place.

### Is XCutors free to use?

Yes. The loader and all bundled utilities are provided free of charge. Individual executors may have their own licensing or tier differences, so check each executor's documentation for details.

### Which Windows versions are supported?

XCutors is designed for Windows 10 and Windows 11 (64-bit). Earlier versions like Windows 7 or 8 may work but are not officially supported or tested.

### Why does my anticomponent flag the loader?

Script executors perform code injection, which is a technique that most anticomponent engines flag as suspicious. Add the XCutors folder to your anticomponent exclusion list. Always download from the official GitHub Releases page to ensure file integrity.

### How do I switch between executors?

Open xcutorsLoader and use the executor selector panel on the dashboard. Simply click the executor name you want to use, then attach and inject as normal. You do not need to close and reopen the loader.

### Can I add my own scripts to the built-in hub?

Yes. Place your .lua or .txt script files into the 'Scripts' subfolder inside the XCutors directory. They will appear in the script hub the next time you refresh or reopen the loader.

### The executor says 'Failed to attach.' What should I do?

Make sure Roblox is fully launched and you are in a game, run the loader as Administrator, and confirm your anticomponent exclusion is active. Also verify that the executor is compatible with the current Roblox version—outdated executors may need an update.

### Does XCutors work on Roblox UWP (Microsoft Store) version?

Compatibility with the UWP version varies by executor. The universal loader will attempt detection for both the standard and UWP clients, but full support is best on the standard Roblox Player downloaded from roblox.com.

### How do I update the executors and loader?

Click the 'Check for Updates' button in the loader settings, or download the latest release ZIP from GitHub and replace your existing files. User scripts and settings are preserved in the 'Config' folder.

### Where can I find scripts to run?

XCutors ships with a small curated script hub. For more scripts, visit community repositories and forums. Always review a script's source code before executing it to understand what it does.
